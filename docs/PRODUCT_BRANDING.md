# Stockpile Product Branding

## Goal

Stockpile should feel like one cohesive product even when multiple external technologies participate in the implementation.

## Customer-facing terminology

| Internal concept | Stockpile UI |
|---|---|
| Long-form clip provider | AI Clip Generator |
| B-roll retrieval | Smart B-Roll |
| Caption animation | Caption Motion |
| Editable external timeline | Timeline Editor |
| Timeline synchronization | Sync Timeline |
| Project export | Editable Project |
| Quality validation | Edit Check |
| Rendering | Render |
| Automatic replacement of a deleted cutaway | Auto Fill Gap |

## Branding rule

Third-party implementation names should not appear in normal:

- buttons
- modal titles
- status messages
- onboarding
- tooltips
- dashboard labels
- marketing copy
- loading states
- error messages

Provider-specific names may remain in:

- source code
- diagnostics
- logs
- tests
- configuration
- developer documentation
- license and attribution documentation

## Tone

Prefer user-outcome language:

- Find the best moments
- Generate clips
- Build an editable project
- Add Smart B-Roll
- Animate captions
- Place text behind the subject
- Render your video

Avoid implementation language in the normal UX.
